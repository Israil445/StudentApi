## StudentApi - ASP.NET Core CRUD Web API

**StudentApi** is an ASP.NET Core Web API that demonstrates basic **CRUD (Create, Read, Update, Delete) operations** for a `Student` database. The project uses **Entity Framework Core** with **SQL Server** and implements **synchronous methods** for simplicity, making it suitable for beginners.  

---

### Features

- **CRUD Operations**: Create, retrieve, update, and delete student records.  
- **Synchronous EF Methods**: Uses `ToList()`, `Find()`, and `SaveChanges()` to simplify database interactions.  
- **Swagger UI**: Provides an interactive interface for testing and exploring API endpoints.  
- **SQL Server Database**: Stores student details including `Id`, `Name`, `Age`, and `Department`.  

---

### Technology Stack

- **ASP.NET Core 10.0**  
- **C#**  
- **Entity Framework Core**  
- **SQL Server**  
- **Swagger UI**
